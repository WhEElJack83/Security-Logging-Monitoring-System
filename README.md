# Security-Logging-Monitoring-System
### Lightweight SIEM using ELK Stack, ModSecurity & NGINX
A lightweight Security Information and Event Management (SIEM) solution built using the Elastic Stack (ELK), NGINX, ModSecurity, Filebeat, and ElastAlert to provide centralized log collection, security event monitoring, and real-time visualization of web application attacks.

The project demonstrates how open-source security tools can be integrated to detect, collect, parse, index, and visualize security events generated by a Web Application Firewall (WAF). By combining log collection, structured parsing, centralized storage, dashboards, and alerting, the solution provides end-to-end visibility into web application security events.

This project was originally developed as an academic project.

---
- Centralized log collection using Filebeat
- Web Application Firewall using ModSecurity with OWASP Core Rule Set (CRS)
- Log parsing using Logstash with Grok filters
- Fast indexing and search using Elasticsearch
- Real-time dashboards and log analysis using Kibana
- Email alerting using ElastAlert
- Monitoring of:
    NGINX Access Logs
    NGINX Error Logs
    ModSecurity Audit Logs
- Detection of common web attacks including:
    SQL Injection
    Cross-Site Scripting (XSS)
    Directory Traversal
    Malicious User Agents
- Interactive Kibana dashboards for security monitoring

# Installation Guide

## 1. Install NGINX

Configure NGINX as the web server.


## 2. Install ModSecurity

Install ModSecurity and enable the OWASP Core Rule Set (CRS).


## 3. Install Filebeat

Configure Filebeat to collect:

- NGINX Access Logs
- NGINX Error Logs
- ModSecurity Audit Logs


## 4. Install Logstash

Configure Logstash to:

- Receive logs from Filebeat
- Parse logs using Grok filters
- Forward parsed events to Elasticsearch


## 5. Install Elasticsearch

Configure Elasticsearch for indexing and searching security events.


## 6. Install Kibana

Connect Kibana to Elasticsearch and create index patterns.


## 7. Configure ElastAlert

Create alert rules for suspicious events and configure email notifications.
